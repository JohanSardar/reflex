# 3D models

For a design review, with the model beside its feature tree and redlines tied to features, read_me("cad") sets it up in one call.

A 3D Embed shows a model on the iPad (RealityKit) and in the web viewer (WebGL). The person turns it
with one finger, zooms with a pinch, pans with two fingers, and drags a part by pressing on it for a
moment and then moving. Their Pencil draws over it.

## Place one

One `add` with `type: "embed"` and `model`: an https URL, or a file path on the Link's computer.

```json
{ "op": "add", "id": "mount", "type": "embed", "w": 640, "h": 460,
  "model": "/Users/ana/cad/motor-mount.glb",
  "params": { "title": "Motor mount", "camera": { "yaw": 35, "pitch": 25, "zoom": 1 } } }
```

- USDZ, `.glb`, or `.gltf` with its `.bin` and images next to it. Reflex reads it once, packs a glTF
  into one `.glb`, and stores it: `model` reads back as `asset:<sha256>`. `repaired` lists its parts.
- A model the person adds (Files, drag and drop) becomes their own 3D Embed. To show it again with
  your own settings, add an Embed with the same `model` asset.
- `camera`: `yaw` and `pitch` in degrees around the model's center (0, 0 looks at its front, +Z;
  yaw 90 from its right; pitch 90 from above). `zoom` 1 fits the model; 2 is twice as close.

## Parts

A part is a named node of the model that holds a mesh. `read(ids: ["mount"], detail: "full")` lists
them in `parts`: each one's `name`, `position` (in its parent's space, in the model's units), and
the `center` and `size` of its box.

## What a Mark on it says

A circle, arrow or strike on the model names the part it points at, with how the person was
looking when they drew it:

```json
{ "id": "m1", "kind": "circle", "on": ["mount"],
  "target": { "kind": "part", "part": "gear", "parts": ["gear"], "label": "part gear",
    "camera": { "yaw": 80, "pitch": 15, "zoom": 1.6, "position": [0.42, 0.2, 0.08], "target": [0, 0.08, 0], "fov": 40 } } }
```

`parts` lists every part the Mark covers, the one it most likely means first. A Mark on empty space
around the model is `{"kind": "local", "label": "the model, away from its parts"}`.

## When the person moves a part

Their move is saved on the Embed, syncs to their other devices, and arrives in the next Send:

```json
{ "kind": "embed_state", "id": "mount", "state": { "part:motor": { "position": [-0.05, 0.2, 0], "moved_by": [0, 0.08, 0], "base": null } } }
```

`position` is where the part is now (in its parent's space), `moved_by` how far it went from where
it was.

## Move, color or hide parts

`patch` the Embed's `params.parts`, by part name:

```json
{ "op": "patch", "id": "mount", "set": { "params": { "title": "Motor mount", "parts": {
  "gear":  { "highlight": "red" },
  "motor": { "position": [-0.05, 0.12, 0], "rotation": [0, 0, 90] },
  "bolt_1": { "hidden": true } } } } }
```

- `position` [x, y, z] replaces the part's position (in its parent's space). `rotation` is degrees
  about X, Y and Z (or a quaternion [x, y, z, w]); `scale` a number or [x, y, z].
- `highlight`: a color name (`red`, `orange`, `yellow`, `green`, `teal`, `blue`, `violet`, `pink`)
  or `true` for orange. `hidden: true` hides the part and what it holds.
- `set.params` replaces all params: send the ones you keep. A position you set wins over the
  person's earlier move of that part; their next move wins over yours.
