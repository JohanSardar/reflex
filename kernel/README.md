# Compatibility kernel

The Rust kernel and WASM/Swift bindings remain temporarily so today's iPad can carry Sends to the Mac through existing document sync. They are not an agent canvas API. T25 owns their removal and native Send replacement.

Build with `npm run build:kernel-wasm`. The generated Rust validation table formerly supplied by the protocol package is retained in `core/src/protocol_generated.rs` solely to keep this build working.

The original design is preserved on GitLab branch `archive/canvas-v0`.
